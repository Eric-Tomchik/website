## Active Lead Magnets

### 1. Business Credit Starter Checklist
- **Format:** PDF
- **File:** `business-credit-checklist.pdf`
- **Location:** Available on `/resources` page
- **Content:** Step-by-step guide for building business credit
  - EIN setup & DUNS number registration
  - First 5 net-30 vendor accounts
  - Monitoring services
  - 0–90 day action plan
- **Purpose:** Companion to "Credit Without a Credit Score" book

### 2. Cybersecurity Quick-Reference Guide
- **Format:** PDF
- **File:** `cybersecurity-quick-reference.pdf`
- **Location:** Available on `/resources` page
- **Content:** Quick-reference security guide
  - Password manager comparison
  - Phishing red flags checklist
  - Wi-Fi security audit steps
  - Incident response template
- **Purpose:** Companion to cybersecurity book

### 3. Credit Checklist Tool
- **Format:** Interactive web page
- **Route:** `/credit-checklist`
- **Purpose:** Free interactive assessment tool
- See [[Credit Checklist Page]]

## Lead Capture Flow
1. User sees lead magnet CTA on resources/blog page
2. Downloads free resource
3. Email captured (if gated) → enrolled in newsletter + drip sequence
4. Follow-up emails promote related paid book

- `LeadMagnet` component — styled CTA with preview of contents + download button
